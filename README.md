# Gerador de Currículo

Aplicação web desenvolvida para criação de currículos profissionais de forma rápida e prática.

Este projeto foi criado com o objetivo de praticar:

- HTML
- CSS
- JavaScript
- Manipulação de DOM
- Criação de interfaces interativas

---

## Funcionalidades

O sistema oferece as seguintes funcionalidades:

1. **Preenchimento em Tempo Real**  
   Os dados digitados são atualizados automaticamente no currículo.

2. **Visualização Instantânea**  
   Preview do currículo enquanto o usuário preenche as informações.

3. **Modelos de Currículo**  
   Alternância entre modelo **Clássico** e **Moderno**.

4. **Cursos Dinâmicos**  
   Permite adicionar múltiplos cursos de forma dinâmica.

5. **Geração de PDF**  
   Possibilidade de exportar o currículo pronto.
